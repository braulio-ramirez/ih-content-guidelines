# Checkboxes (multi-select)

Use checkboxes when the member can select **more than one** item. For exactly one item, use radios.

## Title (required)

- Describes what the list is about.
- 1–3 words for phrases. If it’s a question, keep it concise.
- Sentence case.
- Omit punctuation unless the header is a question.

Examples: `Your availability` / `What days are best for you?`

## Body (optional)

- One sentence ideal, two max. Include punctuation.
- Extra context required for clarity.
- If there is a max number of selections, say it explicitly.

Examples: `Select up to 3.` / `Select all that apply.`

## Checkbox label (required)

- Keep under 3 words when possible.
- Parallel construction: same part of speech, same verb tense.
- Capitalize the first word.
- If labels are actions, they should be **affirmative**, not dissenting (avoid “not”).
- Omit end punctuation.

Examples: `Send me marketing emails` / `Sign up for monthly newsletter`

Not: `Do not send me marketing emails`

## Invalid error

Default: `Select at least one item.`

You may replace “item” with a more specific noun (`Select one medication.` is for a single required pick of that type — prefer `Select at least one medication.` when multiple are allowed).

Do not use the radio default `Select one item.` here — that implies only one selection.
