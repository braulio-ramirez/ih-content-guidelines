# Dropdowns

Members choose from a predefined list. Other names: select, single-select, picker.

Once a value is selected, the member cannot un-select it back to empty (placeholder is gone). A preselected value is OK (e.g. `California`).

## Title

- 1–2 words (3 max).
- Noun phrase.
- Second-person pronouns OK when they apply (`Your pharmacy`).

Examples: `Your pharmacy` / `Medications`

## Placeholder

- Always start with **select**.
- Third person (avoid first/second person in the placeholder).
- 3 words max.

If the field already has a descriptive title, the placeholder can be `Select...`. If not, name the thing: `Select pharmacy` / `Select a pharmacy`.

Examples: `Select pharmacy` / `Select state...`

## Options

We often don’t control option copy. When we do: concise, scannable, 1–2 words (3 max).
