# Lists

Scannable rows of related content (settings, conversations, providers, medications, appointments, checkbox selections). Not for multi-column tables or rich multi-action cards.

## Guiding principle: parallel construction

List **item titles** always follow parallel construction. Same data type every row (a name, a drug, a provider):

- Same part of speech
- Same tense
- Same sentence type
- Same punctuation pattern

Do:

- `Sertraline 50 mg`
- `Metformin 500 mg`
- `Lisinopril 10 mg`

Don’t mix extra facts into only some titles:

- `Sertraline 50 mg (2x daily)`
- `Metformin (as needed)`
- `Lisinopril 10 mg (for 3 days)`

**Subtitles:** parallel only when every row reports the same kind of fact (e.g. all refill dates). If fact types differ (date vs count vs flag), skip parallel construction but keep punctuation consistent.

Same fact type:

- `Refill by Nov. 3`
- `Refill by Dec. 1`

Different fact types (still valid):

- `Refill by Nov 3`
- `3 refills remaining`
- `Flagged by your doctor`

## List title (required)

- Category of items, 3–5 words.
- Sentence case. Omit punctuation.
- Treat as a list header, not the page title.
- Don’t use the word “list” (redundant).

Do: `Your medications`  
Don’t: `Medication List.`

## List subtitle (optional)

- One sentence ideal, two max. Include punctuation.
- Only if it adds information the title doesn’t. Cut filler.

Do: `You have 3 active prescriptions.`  
Don’t: `This is a list of your medications.`

## List item title (required)

- 1–3 words when possible.
- Name the actual entity, not a placeholder.

Do: `Losartan 25mg`  
Don’t: `Prescription 1`

## List item subtitle (optional)

Distinguishing detail so rows aren’t confused. See parallel-construction rules above.

## Preview text / detail line (optional)

Often used in Messages (last reply preview; date and time of last reply).

## Trailing button (optional)

About 1 word. Use a verb.
