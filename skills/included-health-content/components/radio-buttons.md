# Radio buttons (single-select)

Use radios when the member selects **one** item from a group. For multiple items, use checkboxes.

Do not tell people to “select only one” in body copy — the control already implies that.

## Title (required)

- 1–3 words ideal.
- Sentence case.
- Omit punctuation unless the header is a question.

Example: `Choose new visit time`

## Body (optional)

- One sentence ideal, two max. Include punctuation.
- Only if extra context is required.

Example: `You’re rescheduling your existing visit time (Thu, Aug 20, 5:30 PM).`

Not: `Select only one.`

## Radio label (required)

- Keep under 3 words when possible.
- Parallel construction: same part of speech, same verb tense.
- Capitalize the first word.
- If labels are actions, they should be **affirmative**, not dissenting.
- Omit end punctuation.

Examples: `Send me marketing emails` / `Sign up for monthly newsletter`

Not: `Do not send me marketing emails`

## Invalid error

Default: `Select one item.`

You may replace “item” with a more specific noun: `Select one medication.`

Not: `Select at least one item.` — “at least one” implies they can select multiple.

## Assistive technology

Announce the group as a group, the currently selected option, and the number of options.
